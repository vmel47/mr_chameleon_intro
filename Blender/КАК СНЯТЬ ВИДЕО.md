# Как получить видео из Blender

Файл: `walk_ref_02_sign.blend` · Готовый ролик — `Blender\out\walk_ref_02_sign0001-0480.mp4`

---

## Одна кнопка

1. Открой `walk_ref_02_sign.blend` (двойной клик).
2. Нажми **`Ctrl + F12`**.
3. Через ~80 секунд в папке `Blender\out\` лежит готовый **mp4**. Всё.

Никаких PNG, никакой склейки. Blender пишет видео сам.

**Как это настроено** (уже сохранено в файле, менять не надо):

| Параметр | Значение | Где в интерфейсе |
|---|---|---|
| Media Type | **Video** | Output Properties → Output |
| File Format | FFmpeg Video | там же |
| Container | MPEG-4 | Output → Encoding |
| Video Codec | H.264 | Encoding → Video |
| Output Quality | High Quality | Encoding → Video |
| Audio Codec | No Audio | Encoding → Audio |
| Путь | `//out/walk_ref_02_sign` | Output Properties → Output |

В Blender 5.2 появился переключатель **Media Type**. Пока он стоит в `Image`, в списке форматов видео нет
вообще — только картинки. Надо сначала переключить его в `Video`, и тогда появляется FFmpeg. Раньше этого
переключателя не было, формат выбирался сразу.

Blender дописывает к имени диапазон кадров, поэтому файл называется `walk_ref_02_sign0001-0480.mp4`.

---

## Просто посмотреть, не рендеря

- **`0`** на цифровой клавиатуре — вид из камеры. Всё вне кадра залито чёрным.
- **Пробел** — проигрывание в реальном времени. Рендер для этого не нужен.
- **`Esc`** — остановить.

---

## Если надо поменять параметры

Скажи словами, что менять — поменяю и перерендерю:

| Что | Сейчас |
|---|---|
| Скорость ходьбы | 2.0 м/с |
| Знак: вбок / вперёд | 9.0 м / 36.0 м |
| Поворот вправо | старт 5.00 с, длительность 1.5 с |
| Взгляд на знаке | 3.9 с |
| Возврат | старт 10.40 с, длительность 2.2 с |
| Длина ролика | 20 с, 480 кадров, 24 fps |
| Разрешение | 640×360 |

---

## Если рендер идёт слишком долго

Проверь движок: Properties (правая колонка) → вкладка с фотоаппаратом → Render Engine должен быть
**Workbench**, а не EEVEE. На Workbench 480 кадров считаются меньше двух минут, на EEVEE втрое дольше, а
для эталона движения разницы никакой.
