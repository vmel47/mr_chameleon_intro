# АКТУАЛЬНЫЕ ВИДЕОПРОМПТЫ

Единственный рабочий набор находится в [`prompts/current/`](prompts/current/README.md).

Каждый файл в этой папке содержит один полный copy/paste-ready запрос без служебных заметок. Этот файл
не дублирует тексты запросов, чтобы между двумя копиями не возникал дрейф линз, погоды, света или монтажа.

Старая сводная версия сохранена в
[`_archive/SHOTLIST_PROMPTS_BEFORE_CONSISTENCY_LOCK.md`](_archive/SHOTLIST_PROMPTS_BEFORE_CONSISTENCY_LOCK.md).
